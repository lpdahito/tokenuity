MongoDB:
- Connect to MongoDB locally: mongosh <db-name>
- Delete db once connected: db.dropDatabase()
- View options: db.help()
- Start on MacOS: brew services start mongodb-community
- Stop on MacOS: brew services stop mongodb-community
- Create dump file: mongodump --uri mongodb+srv://admin:<PASSWORD>@main.r12qw3b.mongodb.net/main
- Import from dump file: mongorestore --uri mongodb://localhost:27017/trends dump/main
- Update many: db.employee.updateMany({}, {$set: {salary: 50000}})
- Update database from production data: node ./dist/scripts/updateDatabase.js

- Compile: npx hardhat Compile

- Deploy: npx hardhat run scripts/deployTokenuity.js --network base
